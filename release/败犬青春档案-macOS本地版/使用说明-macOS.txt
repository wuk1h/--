败犬青春档案 / MAKEINE ARCHIVE - macOS 本地便携版

支持系统
- Apple Silicon：M1、M2、M3、M4 及后续 arm64 芯片
- Intel Mac：x86_64 芯片

使用方法
1. 使用 macOS 自带的“归档实用工具”完整解压 ZIP。
2. 双击“启动网站.command”。
3. 默认浏览器会自动打开 http://127.0.0.1:4173/ 。
4. 使用结束后双击“关闭网站.command”。

首次运行
- 如果系统提示无法验证开发者，请在 Finder 中右键“启动网站.command”，选择“打开”，再确认一次。
- 文件包优先使用 Mac 已有的 Python 3；如果没有，会自动选择内置的 Apple Silicon 或 Intel 本地服务器。
- 如果提示没有执行权限，请打开“终端”，将解压后的文件夹拖到终端窗口，并执行：
  chmod +x 启动网站.command 关闭网站.command bin/local-server-*

注意事项
- 网站只监听本机地址 127.0.0.1，不会自动公开到局域网或互联网。
- 请保持 site、bin 文件夹与两个 .command 文件位于同一目录。
- 若浏览器没有自动打开，可手动访问 http://127.0.0.1:4173/ 。
