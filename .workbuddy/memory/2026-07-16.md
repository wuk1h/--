## 个人博客项目（C:\Users\wukaix\WorkBuddy\博客教学）

### 技术栈
- Next.js 15.5.20 (App Router) + React 19.2.7 + Tailwind CSS 4.3.2
- Framer Motion（页面动画）、Lucide React（图标）
- 静态导出：`next.config.ts` 配置 `output: 'export'`，`distDir: 'dist'`，`trailingSlash: true`

### 项目结构
- `app/globals.css`：CSS 变量驱动的毛玻璃系统（`.glass` / `.glass-strong` / `.glass-panel`）+ 昼夜模式变量 + 自定义动画
- `app/context/ThemeContext.tsx`：light/dark/system 三态主题，localStorage 记忆，跟随系统媒体查询
- `app/context/MusicContext.tsx`：全局音乐播放器状态，跨页面 Context，播放/进度/音量/播放列表，localStorage 持久化
- `app/components/`：Navbar、ThemeToggle、MusicPlayer（底部浮动毛玻璃播放器）、ContentCard、ContentList、AnimatedSection（客户端动画包装，避免 SSR 调用 framer-motion）
- `app/posts|projects|chatter/`：列表页 + `[id]` 详情页，`generateStaticParams` 静态生成
- `lib/data.ts`：文章/项目/杂谈分类数据
- `lib/storage.ts`：云存储集成（可选，腾讯云 COS + CloudBase）
- `public/music/*.wav`：Python 生成的占位循环音乐（22050Hz，4-5秒）
- `.github/workflows/deploy.yml`：GitHub Pages 部署工作流，artifact 路径 `./dist`

### 关键修复点
1. **SSR + framer-motion 冲突**：首页直接用 `motion.div` 导致服务端组件调用客户端函数报错。解决：创建 `AnimatedSection.tsx` 客户端包装组件（`'use client'`），服务端页面通过它间接使用动画。
2. **lib/storage.ts 构建失败**：动态 `import('cos-nodejs-sdk-v5')` 和 `import('@cloudbase/js-sdk')` 引用未安装 SDK，TS 报 `Cannot find module`。解决：加 `/* webpackIgnore: true */`（阻止 webpack 打包）+ `// @ts-expect-error`（抑制类型错误），保留代码作为可选示例，用户按需 `npm install` 启用。
3. **Buffer 与 BlobPart 类型不兼容**：TS 5.7 新 lib 下 `Buffer<ArrayBufferLike>` 不能赋给 `BlobPart`。解决：`file as unknown as BlobPart` 类型断言（仅限未启用的 CloudBase 分支）。
4. **音乐文件体积**：初始 44100Hz/8-12秒 WAV 过大（2.6MB），优化为 22050Hz/4-5秒（约 400KB/个）。无 ffmpeg，用 Python `wave` 模块生成正弦波合成音色。

### 部署
- GitHub Pages：推送到 `main` 分支自动触发 `.github/workflows/deploy.yml`，需在仓库 Settings → Pages → Source 选 "GitHub Actions"。
- 云存储：默认未安装 SDK，按需启用（见 README）。

## 沉浸式阅读展示页（/novel/）

基于桌面 `C:\Users\wukaix\Desktop\败犬\日文\` 下的 1-8 卷 + SSS 卷日文 epub，用真实官方插画替换 SVG，构建沉浸式阅读展示。

### 资源提取
- `scripts/extract_assets.py`：批量解压 epub，提取 cover + 前 6 张彩色插页。兼容三种版式：images/、OEBPS/Images/、item/image/，扩展名 .jpeg/.jpg。共提取 57 张到 `public/makeine-img/{v1..v8,sss}/`。
- `scripts/extract_text.py`：从各卷章节 html/xhtml 提取纯文本（处理 ruby 注音、h 标签），每卷取前 5 个最大章节截前 400 字，共 45 段日文原文片段到 `lib/makeine-text.json`。
- `scripts/generate_novel_data.py`：扫描图片目录生成 `lib/makeine-novel-data.ts`（9 卷 + 54 plates 清单）。

### 视觉与交互
- 美学：Luxury/refined 精致奢华（深石板底 + 暖金聚光 + 樱粉点缀，避紫蓝渐变）
- 字体：复用 Zen Maru Gothic（含日文汉字）+ Kaisei Decol
- Hero：全屏 v1 封面 + ken-burns 缓慢缩放平移（24s alternate）
- 卷弧形画廊：8 卷封面沿 180° 半圆 3D 排列（perspective 1400 + rotateY + translateZ），hover 放大微旋
- 插图墙：54 张 plate 网格 + 鼠标移动 3D tilt（perspective rotateX/Y）+ IntersectionObserver 淡入
- 缓慢转动：vol-card hover scale+rotate，plate hover scale
- 画面流转：ken-burns 24s 无限 alternate 缩放平移 + scroll fade-in
- 二级弹窗：点击 plate/卷 → 全屏 modal（毛玻璃 backdrop + 缩放进入），左插图 / 右日文原文 + 登场角色，Esc/外部点击关闭
- 关键 CSS 动画：ken-burns、modal-fade-in、modal-scale-in、fade-up（写在 globals.css）

3. **两页面一致性仅 4/10**：首页和 novel 像两个不同网站，切换时无过渡
4. **响应式桌面端 8 分 / 移动端 4 分**：VolArc 弧形画廊固定尺寸在移动端溢出，CharacterCard 信息过载
5. **动画是全站亮点**：ken-burns / 3D tilt / modal 进场动画质量很高（8/10）

### 总体评分：5.9/10
- 视觉上限高（桌面端精致），但下限低（移动端/无障碍需大改）
